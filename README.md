## 모델 선정 이유

성남시청 내부에서 민원, 공문, 회의록, 내부 지침과 같은 자료를 다룰 때는 외부 API 전송에 대한 보안 우려가 생길 수 있습니다. 따라서 내부망 또는 통제된 환경에서 사용할 수 있는 SLM 후보를 검토할 필요가 있다고 판단했습니다.

`Phi-3.5-mini-instruct`는 3.8B 규모로 비교적 가벼운 편이며, 과제 조건인 1B~7B 범위에 들어갑니다. 또한 128K 장문 컨텍스트를 지원하므로 공공행정 문서처럼 길고 맥락이 많은 자료를 요약하거나 질의응답하는 데 활용 가능성이 있습니다.

## 주요 활용 가능 업무

- 공문, 보고서, 회의록, 내부 지침 요약
- 민원 처리 매뉴얼과 조례 기반 질의응답
- 부서별 문서 검색을 결합한 RAG 시스템
- 민원 내용 유형 분류 및 답변 초안 작성
- 회의자료에서 결정사항, 담당 부서, 처리 기한 추출

## 한계와 주의사항

이 모델은 한국어를 지원하지만 성남시 행정문서나 국내 법령, 조례에 특화된 모델은 아닙니다. 공개 데이터 기준 컷오프도 2023년 10월이므로 최신 정책, 예산, 지원사업, 법령 정보는 모델 자체 지식에 의존해서는 안 됩니다.

실제 행정업무에 적용하려면 최신 내부 문서와 공식 근거를 연결하는 RAG 구성이 필요하며, 최종 답변은 담당자가 검토해야 합니다. 또한 GPU 사양, 동시 사용자 수, 내부망 구성, 개인정보 비식별화, 권한 관리와 로그 관리 기준도 함께 검토해야 합니다.

## 종합 의견

`Phi-3.5-mini-instruct`는 초기 검토 단계에서 성남시청 내부 AI 후보 모델로 살펴볼 가치가 있습니다. 7B급 모델보다 운영 부담이 낮고, 장문 컨텍스트를 지원해 행정 문서 분석과 내부 지침 기반 질의응답에 적합한 편입니다.

다만 최종 도입 모델은 정보통신과의 실제 GPU 사양, 보안정책, 내부 문서 규모, 동시 접속 수, 유사 지자체 구축 사례를 확인한 뒤 다시 비교하는 것이 적절합니다.
